### 🚀 Selected Projects

**01. Smart Floorplan - GCN based Congestion Predictor**

Graph Neural Networks for predicting routing congestion in chip floorplans using macro placement and netlist connectivity.

- Represented floorplans as graphs with macro-level node features and connectivity edges.
- Implemented a three-layer Graph Convolutional Network using PyTorch Geometric.
- Developed synthetic data generation, model training and inference pipelines.
- Reported approximately 82% test accuracy and 0.78 F1 on synthetic, heuristic-labelled test data.

[Explore Repository →](https://github.com/la9fer/smart-floorplan-GCN)

**02. ECG Anomaly Detection - Deep Learning & Classical ML**

Developed an ECG arrhythmia detection pipeline using 1D CNNs and classical machine learning baselines.

- Compared CNN, SVM, Random Forest and Logistic Regression.
- Implemented patient-wise data splitting and model evaluation.
- Developed real-time-style inference and ESP32/ADS1293 serial integration.
- Reported CNN F1 score of 95.24% on the project's test split.

[Explore Repository →](https://github.com/la9fer/ecg-anomaly-detection)

**03. Placenta MRI Segmentation - Deep Learning**

Implemented a U-Net-based medical image segmentation pipeline using PyTorch and MONAI.

- Custom encoder-decoder architecture with residual units.
- Data augmentation, Dice loss and validation.
- Reported Dice score of 0.860 and IoU of 0.770 in the implemented evaluation.

[Explore Repository →](https://github.com/la9fer/placenta-mri-segmentation)

**04. Finite Element Solver for Elliptic PDEs**

Implemented a P1 finite element solver for the 2D Poisson equation.

- Element stiffness matrix computation and global assembly.
- Triangular mesh refinement and sparse linear systems.
- Numerical error and convergence analysis.

[Explore Repository →](https://github.com/la9fer/fem-elliptic-pde-solver)

**05. Asian Option Pricing - Numerical Research**

Investigated numerical methods for solving the Asian option pricing PDE.

- Compact finite difference methods.
- BDF4 time integration and grid stretching.
- Numerical accuracy, convergence and benchmark comparisons.

[Explore Repository →](https://github.com/la9fer/asian-option-hu-gan-on-patel-mehra)
